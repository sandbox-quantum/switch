# Cisco Webex

_Connect Cisco Webex spaces to Switch rooms using a self-created Webex Bot_

Webex connects to Switch through a self-created Webex Bot. Inbound events are delivered over HTTPS webhooks, verified using HMAC signatures, and outbound replies support threading (`parentId`) and Adaptive Cards.

## 1. Create a Webex Bot

1. Go to [Webex for Developers](https://developer.webex.com/) and sign in.
2. Click your profile avatar -> **My Webex Apps** -> **Create a New App** -> **Create a Bot**.
3. Fill in:
   - **Bot Name**: e.g., `Switch Agent`
   - **Bot Username**: unique handle, e.g., `switch-bot@webex.bot`
   - **Icon**: optional avatar
   - **App Description**: A short summary of the bot
4. Click **Add Bot** and copy the **Bot Access Token**. This token is shown only once.

## 2. Connect in Switch Console

1. Open **Switch Console** -> **Connect a messaging app** -> choose **Cisco Webex**.
2. Fill in the connection form:
   - **Bot Access Token**: The token copied from the developer portal.
   - **Webhook Secret**: A secure random secret string (used to sign and verify incoming webhook requests).
   - **Bot Email**: (Optional) The bot's email address (e.g., `switch-bot@webex.bot`), used to clean `@mention` markup.
3. Save the connection. Switch provides you with the unique webhook endpoint:
   `https://<YOUR_SWITCH_DOMAIN>/messaging/bridges/<BRIDGE_ID>/events`

## 3. Register the Webex Webhook

In Webex Developer Portal or via the Webex REST API (`POST https://webexapis.com/v1/webhooks`):
- **Name**: `Switch Bridge`
- **Target URL**: The webhook URL generated by Switch.
- **Resource**: `all` (or create separate webhooks for `messages`, `memberships`, `attachmentActions`)
- **Event**: `all` (or `created`)
- **Secret**: The exact same **Webhook Secret** entered into Switch Console.

## Behavior & Capabilities

- **Group Spaces (Rooms)**: Webex bot privacy rules deliver messages only when the bot is `@mentioned` in group spaces. The bot strips its own mention before handing the text to the agent.
- **Direct 1:1 Chats**: All messages sent to the bot in a direct space are delivered automatically without requiring a mention.
- **Threading**: Webex threads use `parentId`. Replies sent by agents stay in the originating thread.
- **Adaptive Cards**: Approval and question cards are rendered as Adaptive Cards v1.3. Submissions trigger Webex `attachmentActions` and are dispatched to the waiting session.
- **Message Edits**: The Webex bot REST API does not support editing standard plain text messages (`PUT /v1/messages` is not permitted for bots). Text edits are not mirrored to Webex; card updates are supported where applicable.
- **Attachments**: Supports file uploads and downloads up to 100MB.

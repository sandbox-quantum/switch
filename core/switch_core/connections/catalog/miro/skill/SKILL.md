# Miro

The `miro` MCP server provides tools to search boards, summarize diagrams and visual
planning artifacts, extract decisions, and create supported board items.

## What the grant reaches

- **You act as the owner of this connection.** You can view and manage
  Miro boards and content that your owner has access to within the authorized team.
- **Board inspection and summarization:** Search boards, inspect items, sticky notes,
  cards, connectors, and frames.
- **Never print, log, or store credentials.** Authentication and token renewal
  are handled transparently by the session host.

## Tasks and tools

- **Board search & discovery:** Search for boards by name or keyword, and list recently
  modified team boards.
- **Content extraction:** Read frames, shapes, text, and sticky notes to summarize
  architecture plans, retrospective items, and meeting notes.
- **Action items & decisions:** Extract structured tasks, user stories, and action
  items from visual brainstorm sessions.
- **Item creation:** Create sticky notes, cards, or shapes when explicitly requested
  by the user.

## Safety and etiquette

- **Read before writing:** Always search and inspect existing board structure and frames
  before proposing changes or creating items.
- **Explicit confirmation for changes:** Creating, moving, or deleting board items
  modifies a shared team workspace. Always explain intended changes and confirm with the
  user before performing writes.
- **No unprompted deletions:** Never delete boards, remove content frames, or clear
  board items without explicit user instruction.
- **Respect team permissions:** Board access strictly respects your owner's Miro team
  membership and role.

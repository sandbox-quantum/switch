# Calendly

The `calendly` MCP server provides tools to inspect scheduling availability, list event
types, retrieve booking links, view scheduled meetings, and manage appointment workflows.

## What the grant reaches

- **You act as the owner of this connection.** You can view availability and manage
  scheduled events that your owner has access to in Calendly.
- **Event types and booking links:** Retrieve personal and team event types and share
  scheduling links with colleagues or clients.
- **Never print, log, or store credentials.** Authentication and token renewal
  are handled transparently by the session host.

## Tasks and tools

- **Availability inspection:** Check user or team busy times and scheduling windows
  to coordinate meetings.
- **Event type retrieval:** List active event types and retrieve direct booking URLs.
- **Scheduled event lookup:** View details, attendees, and questions for upcoming meetings.
- **Appointment changes:** Cancel or reschedule an event only when explicitly instructed.

## Safety and etiquette

- **Read before scheduling:** Always inspect availability and existing commitments
  before proposing a meeting time or booking slot.
- **Explicit confirmation for changes:** Creating a booking or cancelling a meeting
  notifies attendees and alters calendars. Always confirm attendee details, times, and
  meeting reasons before creating or cancelling events.
- **No unprompted cancellations:** Never cancel an existing meeting without explicit user
  authorization in this conversation.
- **Protect attendee privacy:** Treat invitee names, emails, and response answers as
  confidential attendee data.

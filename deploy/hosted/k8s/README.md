# Hosted agents v2: the cluster objects

These are the cluster-side objects the v2 boxes run on, as they run on the test cluster, with server-set fields
(uid, resourceVersion, timestamps, managed fields, last-applied annotations, status) removed. Per-box objects
(each user's namespace, `box` StatefulSet, disks, NetworkPolicies and Secrets) are not here: the provisioner makes
them from `controller/src/switch_hosted_controller/box_operator.py`.

| File | What |
|---|---|
| `10-namespaces.yaml` | `switch-hosted`, `egress-proxy`, `egress-lists`, `switch-drain-room` |
| `11-classes.yaml` | PriorityClasses `switch-placeholder`, `switch-shared-services`; RuntimeClasses `gvisor`, `gvisor-tuned` |
| `20-cluster-rbac.yaml` | ClusterRoles and bindings for the provisioner, the hosted controller, the egress-lists generator, drain, restart and the box watch |
| `30-admission-policies.yaml` | ValidatingAdmissionPolicies P1 to P8 and the three operator policies, with their bindings. Every one is `failurePolicy: Fail` and matched to one account |
| `40-switch-hosted.yaml` | The provisioner, hosted controller, operator and drain Deployments; their NetworkPolicies, Roles and ConfigMaps (box size and allowed images in `switch-box-operator-config`) |
| `50-egress-proxy.yaml` | The shared squid: Deployment, Service, `squid-conf` and `squid-reload`. Its NetworkPolicy is `../egress/egress-proxy-networkpolicy.yaml`. The per-box `squid-boxes` ConfigMap and the `squid-passwd` Secret are generated by the egress-lists generator and are never in the repo |
| `51-egress-lists.yaml` | The egress-lists generator's Deployment, account, Role and NetworkPolicies |
| `60-switch-drain-room.yaml` | The drain room's Role, RoleBinding and one-placeholder quota |

## Placeholders

Each must be replaced before applying; none has a default. `../fill-placeholders.py` fills them all, checks each
value, and writes a copy ready to apply, outside the repo (see `../DEPLOY.md`). It also sets P4's zone rule and the
cluster's `kubernetes` Service address in the NetworkPolicies (`172.20.0.1` on the test cluster).

| Placeholder | Value |
|---|---|
| `__SERVER_IP__` | the Switch server's address that boxes reach (the agents' one allowed ipBlock) |
| `__API_SERVER_IP_1__`, `__API_SERVER_IP_2__` | the cluster API server's private endpoint addresses (NetworkPolicy egress) |
| `__AGENTS_SUBNET__` | the agents' node subnet, the source squid allows |
| `__ZONE__` | the zone boxes run in |
| `__BOX_IMAGE__` | the current box image, by digest |
| `__PREVIOUS_BOX_IMAGE_1__` … `_3__` | older box images still allowed while boxes move, by digest |
| `__CONTROLLER_IMAGE__` | the hosted controller image (`controller/Dockerfile`), by digest |
| `__EGRESS_LISTS_IMAGE__` | the egress-lists generator image (the same build), by digest |
| `__PAUSE_IMAGE__` | the placeholder pod's image, by digest |
| `__BOX_CA_CERT__` | the CA certificate (PEM) that signs the Switch server's certificate. Always needed: the provisioner refuses to start without one, so for a publicly trusted certificate give its public CA |

## Known for later

- The box namespaces carry `app.kubernetes.io/part-of: hosted-agents-test`, which P1 requires and
  `box_operator.py` writes. It's the test cluster's name; renaming it needs the provisioner and P1 changed together,
  with a move for existing boxes.
- P4's zone rule reads `^eu-west-3[abc]$`.
